# Changes

- A collaborative sidebar keeps pins first, shows human/agent last-editor icons, refreshes changed/new pages automatically, and tucks settled pages into a collapsed section. Editing a settled page brings it back to Attention. Clearer titles, quieter previews and compact ages such as `1d` make rows easier to scan.

- Start writing from a suggested local folder with one click. Simpler Mac onboarding also offers a secondary remote connection, optional folder help and clearer retry guidance.

- Cleaner slash menu with short labels, formatting glyphs and compact spacing.

- Navigate Markdown sections with a floating heading rail: hover for a preview, click to jump, or use arrow keys and Enter. The current section is highlighted as you scroll.

- Sidebar notes show a plain-text preview and last-edited age, with actions on hover/focus. The wider sidebar can be dragged to resize and remembers its width.

- Organize notes on personal Kanban boards in the Mac sidebar. Add existing or new notes, move cards, and settle boards; restore them from Settings → Boards. Board layout is stored locally, separately from the Markdown vault.
- Add notes to a board and column directly from the note action card, with search and duplicate indicators in the board's Add note flow.
- New local brains created in Mac onboarding start with a pinned Today page: 10 Main focus, 5 Secondary focus and 5 The rest checkboxes. Unpin or settle it to put it away.
- Related pages are back below notes. Copy/Delete actions stay visible in a sticky page card with folded saved-version details.
- Mac connection settings use individual cards, clear Local/Remote and Active labels, and a compact + control with a matching add/edit form. Connection health appears once in the sidebar.
- A thinner, muted search focus ring. Softer hover feedback across all light/dark themes. Icon-only buttons highlight their glyph without changing the background; compact controls have more consistent sizing and centering.
