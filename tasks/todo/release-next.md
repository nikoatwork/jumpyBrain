# Changes

- **Drawings for agents:** `jumpybrain drawings list`, `show` and `update --if-match` read and replace Excalidraw drawings on a local brain or with `--target-url`, and `jumpybrain tree` now lists your drawings. Drawings still stay out of search and recall.
- **Project memory beside your personal brain:** run `jumpybrain project trust` once inside a repository with its own `memory/` folder, and commands and installed skills there use that project's memory; elsewhere they keep using your personal brain. A project memory you haven't approved stops commands with the exact command to approve it, instead of quietly saving to your personal brain, and a cloned repository can't approve itself. `jumpybrain project status` shows which brain is in use. Agents may save durable project decisions without asking only when the project sets `"capture": "durable"` and you approve with `--allow-capture`. Skills update with the installation; customized skill files are left alone.
- **Pinned project installs:** the CLI package attached to each GitHub release can be installed as a project dependency, and a `@tobilu/qmd@2.8.3` installed in the same project is now found automatically, with no absolute paths. `doctor` shows which search engine it selected and where it came from.
