# Changes

- Graph search now uses the same search as the rest of the app, including note contents and semantic matches when available.

- Settle or snooze notes from the sidebar or editor; due notes return automatically, with state kept in Markdown.
- Simplified the sidebar with Search/New note icons, a sun/moon toggle, and consistent typography.

- Mac updates stay in the sidebar: download, background preparation, then relaunch. Updating from the app or CLI keeps supported paired installations aligned, with safe saves and recovery.
- Pasted Markdown now renders supported formatting immediately in the editor.
- Added configurable feedback delivery with optional diagnostics and retained drafts when delivery cannot be confirmed.
