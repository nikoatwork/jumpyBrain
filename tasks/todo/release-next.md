# Changes

- Agents can create, organize and inspect personal Mac boards with the optional `jumpybrain board` namespace. Initiative status includes current note excerpts and explicit evidence gaps; board deletion keeps notes. Requires the running updated Mac app.

- Fixed mixed sidebar sections and stacked bottom controls. Graph, Settings and Feedback stay grouped left, with updates anchored at the bottom right and open spacing instead of a divider. Theme choices live in Settings → Appearance, and the update check uses a quieter borderless icon; full-width row highlighting and earlier title/preview truncation keep ages clearly separated. Settled has a roomy, muted row with a right-aligned count and chevron directly above the icons; brain selection sits above it. Sidebar lists scroll without visible scrollbars.

- Agents can send feedback directly with `jumpybrain feedback`, including stdin, a dry-run preview and JSON delivery receipts. Agent guidance explains reporting bugs; release preparation includes a live feedback review.

- A collaborative sidebar keeps pins first, shows human/agent last-editor icons, refreshes changed/new pages automatically, and tucks settled pages into a collapsed section. Editing a settled page brings it back to Attention. Clearer titles, quieter previews and compact ages such as `1d` make rows easier to scan.

- Start writing from a suggested local folder with one click. Simpler Mac onboarding also offers a secondary remote connection, optional folder help and clearer retry guidance.

- Cleaner slash menu with short labels, formatting glyphs and compact spacing.

- Navigate Markdown sections with a floating heading rail: hover for a preview, click to jump, or use arrow keys and Enter. The current section is highlighted as you scroll.

- Sidebar notes show a plain-text preview and last-edited age, with actions on hover/focus. Refreshing previews no longer makes ordinary notes appear due. The wider sidebar can be dragged to resize and remembers its width.

- Organize notes on personal Kanban boards in the Mac sidebar. Start a board with one click and a playful productivity name such as “Cozy Focus Foxes,” unique among active and settled boards. Rename titles inline, and search or create notes directly in each column with keyboard selection and safe retries. Cards show a three-line content preview with compact right-side action icons. Move cards and settle boards; Settings → Boards provides a compact list to rename, settle/restore or delete boards while keeping their notes. Settled-board messages link directly to settings. Board layout is stored locally, separately from the Markdown vault.
- Add notes to a board and column directly from the note action card, with search and duplicate indicators in the board's Add note flow. Column headers place a clearer plus button beside the title and omit card counts.
- New local brains created in Mac onboarding start with a pinned Today page: 10 Main focus, 5 Secondary focus and 5 The rest checkboxes. Unpin or settle it to put it away.
- Related pages are back below notes. A compact page card stays tucked against the right edge, with Copy/Delete icons, a quiet Add to board row and folded saved-version details. Hover targets have consistent padding and rounded shapes; board controls and navigation share the same treatment.
- Mac connection settings use individual cards, clear Local/Remote and Active labels, and a compact + control with a matching add/edit form. Connection health appears once in the sidebar.
- A thinner, muted search focus ring. Softer hover feedback across all light/dark themes. Control explanations wait briefly before appearing on hover, keeping pointer movement calm while keyboard help stays immediate. Icon-only buttons highlight their glyph without changing the background; compact controls have more consistent sizing and centering.
