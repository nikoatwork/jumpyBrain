# Changes

- Organize notes on Kanban boards in the Mac sidebar: one-click creation with playful unique names, inline renaming, searchable note creation, card previews, movement and settling. Add notes from the page action card and manage boards in Settings without deleting their notes.
- Agents can create, organize and inspect boards through `jumpybrain board`, using local brains or remote targets without the Mac app. The CLI and Mac share canonical `boards/<UUID>.json` files and write permissions; status reports current note evidence and gaps. This replaces development builds’ app-support collections and app-only flags without a legacy importer.
- A collaborative, resizable sidebar keeps pins first, shows human/agent last-editor icons, refreshes changed pages and groups settled pages. Clearer previews and ages, full-width rows, hidden scrollbar chrome and quieter bottom controls make navigation easier to scan; editing a settled page brings it back to Attention.
- Start writing with one click in a suggested local folder, or connect to a remote brain. New local brains start with a pinned Today checklist; connection settings use clearer cards and Local/Remote labels.
- Jump between Markdown sections with a floating heading rail and pointer or keyboard previews. A compact slash menu, restored related-page footer and tucked-away page action card keep writing controls close by.
- Softer hover feedback, delayed control explanations, consistent icon buttons and a quieter search focus ring reduce visual noise. Theme choices live in Settings → Appearance.
- Agents can send feedback with `jumpybrain feedback`, including stdin, a dry-run preview and JSON delivery receipts.
