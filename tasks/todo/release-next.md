# Changes

- Remote connections now explain editing permissions and access-key failures with direct Settings actions; connection testing retains keyboard focus. Older memory servers show board-update guidance while keeping notes usable, with unsupported board changes disabled.
- The Mac sidebar now groups pinned and active pages together, places boards above them, and keeps Settled above the brain/footer controls. Create boards from the compact toolbar button; short action tooltips and filled pins make actions easier to read.
- Settling a page also unpins it and visibly clears its row with a subtle exit and closing gap (instant with Reduced Motion). Undo restores the prior pin; Bring back leaves the page unpinned.
- Boards can optionally expand into columns and pages in the sidebar. Enable **Show pages in sidebar** in board settings, then jump straight to project pages; expansion is remembered per device and brain, including read-only connections. The general page list now has no heading.
