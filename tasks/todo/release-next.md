# Changes

- Browse nested note folders in a collapsible right sidebar, with focused title/path search, mouse and keyboard navigation, and direct note opening.
- Obsidian import guidance and CLI summaries now explicitly explain that Markdown filenames and nested folders are preserved under `notes/`.
- Agents can install and verify the CLI, detected integrations and Mac app in one operation. Setup uses verified release assets, private Node/search dependencies when needed, structured completion diagnostics and recoverable retries; it no longer trusts an unrelated checkout in the current directory. Mac native build tools remain required.
