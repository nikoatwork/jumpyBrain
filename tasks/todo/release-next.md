# Changes

- Folders supports right-click file rename, copy link and guarded deletion, new empty folders, and drag-and-drop moves with a keyboard Move to option.

- Search on web and Mac hides the page you are currently viewing, keeping results focused on other pages.

- Page actions can copy a local note’s absolute file path, show its board memberships, and offer compact Add to board and clearer More info controls.

- Sidebar toolbar actions use icons with no resting borders; Home keeps a border while active, and Search no longer shows a text label.
