# Changes

- Graph search now uses the same search as the rest of the app, including note contents and semantic matches when available.
- Removed graph note-count summaries, node-limit messages, and filter hints for a quieter view.
- Settle or snooze notes from the sidebar or editor; due notes return automatically, with state kept in Markdown.
- Simplified the sidebar with Search/New note icons, a sun/moon toggle, and consistent typography.
- Mac updates use compact sidebar download and relaunch icons, with background preparation, safe saves, and recovery.
