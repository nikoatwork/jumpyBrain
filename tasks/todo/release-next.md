# Changes

- Search no longer repeats index-maintenance warning pop-ups. Quiet recovery controls, background updates and actionable search errors remain available.
- Settle, Snooze, Bring back and Undo now work for the open saved note. Clean notes load changed saved text after a backend restart without unnecessary draft review; unpublished changes remain protected.
- Search ages now say Edited, and More info separates Written from Last edited. Related notes show two-line hover/focus previews. The toolbar Link button is removed; inline reference completion remains. Deletion uses one warning and Cancel/Delete actions.
