# Changes

- New daily notes retain their selected local calendar day for dated recall and dream windows.

- Word and line deletion save reliably in existing notes, including keyboard shortcuts and repeated text.

- The packaged Mac app starts normally from agent shells that inherit Electron's Node-mode variable; reopening after Quit works independently of Start at Login.

- The Mac app reconnects to a restarted local brain backend without quitting, retaining unpublished drafts for review and restoring notes, boards and search.

- Doctor offers an explicit read-only lexical probe with content-free execution results; readiness guidance distinguishes engine presence, index metadata and untested semantic relevance.
- Agent guidance starts with short prerequisites and discoverable CLI topics. Local lint has an explicit observational `--preview`; report writes still require `--apply`.
- Manage local app connections from the CLI through the running companion’s save barriers. Doctor/status show target sources and honor configured CLI roots independently of app selection.

- Desktop updates retain live backend runtimes and safely bound verified obsolete staging; backend startup and cleanup previews preserve signed Mac app resources. Managed integration refresh preserves customized files. Backend inventory and clearer shutdown diagnostics improve local inspection.

- CLI help supports `--help`, `-h` and `help <command>` for commands, namespaces and recipes without running operations. Root help is shorter; plain retrieval and other operational commands reject misspelled, missing and repeated flags.
- Self-hosted Docker builds include the browser build scripts and locked search/runtime dependencies, run without root, and have a disposable build/recovery check.

- Clearing a fresh note through its empty heading and blank lines saves reliably; editor failures use plain-language, dismissible recovery toasts.

- Editor section indicators are half as wide, with thicker H1 and H2 marks to make heading levels easier to distinguish.
- Editor attribution moves from sidebar icons to a floating saved-note hint when selecting text; unavailable section history stays explicit.
- Set your display name during Mac onboarding or in Settings, shared with CLI identity setup; agent writes can show owner-prefixed client labels such as Alex · Codex.
