# Changes

- **Shared-brain access.** The Mac app follows your server key’s role. Settings shows what your key permits, and blocked actions explain why and link to Settings. The old per-device editing switch is gone. Saving a connection in this release updates the profile file to a format older Mac apps cannot open.
- **Moving to a shared server.** `jumpybrain diff --root <local> --target-url <server>` compares notes and drawings. `jumpybrain migrate remote` previews the move, and `--apply` copies missing notes and drawings and pushes newer local notes. It preserves newer server edits and leaves differing drawings for you to resolve. Update the destination server first.
- **Manage remote connections from the CLI.** `connections add --url <server> --key-env <VARIABLE>` or `--key-stdin` adds a connection without opening Settings and reuses a matching key already in the app’s `.env`. `connections test`, `status --all`, and `access whoami` show connection health, which key the CLI uses, effective permissions, and missing local folders. Deleted brain folders stay deleted.
- **Headless installs.** A remote-only release install runs without npm or QMD. The installer reports its filesystem changes, and `--read-only-commands` blocks mutation commands. Local installation and interrupted-install retries still provision the brain with that option enabled.
- **Project memory and pinned installs.** Run `jumpybrain project trust` to use a repository’s own `memory/` folder. The `--allow-capture` option enables automatic durable capture when the project opts in. Install the CLI from a GitHub release as a project dependency and it can find the pinned QMD installed beside it. `project status` and `doctor` explain which brain and engine are selected. Codex sandbox errors now identify the restriction and suggest rerunning with approval.
- **Calmer sidebar.** Active pages take one line, with a last-editor icon when the editor is known and date groups for recent work. Settled and Drawings have headers with counts and Drawings has a new-drawing button. Agents can use `drawings list`, `show`, or hash-checked `update` on local or shared brains and see drawings in `tree`.
- **Clearer CLI responses.** `show --json` includes the note body separately from frontmatter. Multi-keyword text searches with no hits suggest trying fewer terms. Authentication errors point to the Bearer authorization header.
