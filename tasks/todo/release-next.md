# Changes

- Navigate back in the Mac app with mouse Back, Cmd+[ or supported three-finger swipes, with five previous pages and existing draft protection.
- Type `@` to search for a page reference in the Mac editor; newly completed or opened missing references can create their target page, with retry recovery.
- Graph search now uses shared content and semantic search when available, with quieter graph controls and fewer status messages.
- Settle or snooze notes from the sidebar or editor; due notes return automatically, with state kept in Markdown.
- Simplified sidebar controls, theme switching and typography; Mac update icons support background preparation and explicit relaunch.
