# Changes

- Managed CLI and Mac app installs use Homebrew's stable Node link when available. Desktop shows a repair command when its runtime cannot start, and the installer can reclaim abandoned app-update locks when ownership is verifiable.
- Shared note links offer **Connect** when a browser needs an access key. Entering a valid key opens the original note and remembers access for the existing 24-hour browser session.
- The installer offers profiles: personal memory for agents (default, CLI with keyword search), the Mac app, connecting agents to a team brain, or browsing one in the browser (nothing to install). Run in a terminal without options, it asks and Enter accepts the default; agents and `--json` runs never get asked. Each choice explains what you get, then download size, disk, what runs and what uses the network. Existing `--with-app` and `--remote-only` keep working.
- Smart search is an optional add-on: it also finds notes that say the same thing in other words, using a 334 MB model that runs only on your computer. Choose it with `--smart-search` at install, or later with `jumpybrain smart-search on`; `jumpybrain smart-search off --remove-model` switches back and frees the space. `status` and `doctor` now say "keyword search" or "smart search".
