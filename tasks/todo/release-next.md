# Changes

- Editing fixes cover clearing fresh notes and deleting existing words and lines; recovery messages are plain-language, dismissible toasts.
- The Mac app reconnects after a local backend restart while retaining unpublished drafts for review. Packaged builds also launch from agent shells that inherit Electron's Node-mode variable.
- Desktop updates protect live backend runtimes and conservatively remove verified obsolete staging. Backend startup preserves signed Mac app resources, and managed integration refresh preserves customized files.
- CLI help supports `--help`, `-h` and `help <command>` without running operations. Shorter guidance offers discoverable topics, stricter arguments catch mistakes, and local lint supports observational `--preview`.
- Manage local app connections through the CLI with the running companion's save barriers. Doctor/status explain target sources, and doctor offers an explicit read-only lexical probe.
- New daily notes retain their selected local calendar date. Editor heading indicators are more compact, selection shows saved-note attribution, and Mac onboarding/Settings share display names with CLI identity setup.
- Self-hosted Docker builds include required browser build scripts and locked search/runtime dependencies, run without root, and have a disposable retrieval and recovery check.
