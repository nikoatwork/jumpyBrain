# Operating arrangement

Belltower repair sessions must finish before seventeen hundred.

This timing applies to the accepted trial. Check the host confirmation before offering a different timetable. An informal extension can create a commitment that the host cannot cover.

## Before starting

Read the accepted scope, check that the assigned people are present, and keep the stop procedure available. Record an unresolved discrepancy rather than filling it with an assumption from another project.
