# Accepted operating scope

Belltower may run a hand-tool repair table for registered adults; mains-powered repairs and drop-in access remain outside approval.

The responsible coordinator accepted this bounded scope on October 4 after reviewing the host arrangement. A later discussion remains a proposal until the responsible person records a replacement decision.

## Reason for the limit

The trial tests whether the supported activity can run reliably with the people and facilities already available. Increasing the audience or adding a different activity would answer a different question.
