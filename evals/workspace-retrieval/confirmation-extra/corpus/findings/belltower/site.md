# Host confirmation

The library caretaker locks the side entrance at seventeen fifteen and cannot supervise a later departure.

The host supplied this limit for the current trial. A participant suggestion or calendar change does not create extra staffing or access. Confirm a changed arrangement in writing before offering additional sessions.

## Boundary

The host confirmation concerns availability. It does not itself approve a different audience, activity, equipment set, or route.
