Already using jumpyBrain with an AI assistant?

Use the same folder to see the same notes. The usual folder is ~/.jumpybrain/memory. To find a hidden folder, press ⌘⇧G in the chooser and paste its path. The ~/.jumpybrain/app folder contains software, not notes. Choosing a folder here doesn’t change your assistant’s settings.
