# Executable extension host

## Responsibilities

- Expose `createExtensionHost({directory, safeMode?})` plus local management re-exports. The gateway composes one host; browser tabs share registrations rather than activating another Node factory. Ordinary CLI/runtime imports do not construct a host.
- Activate default factories with registration/state APIs, never memory or a process-global brain target. Commands, panels, themes, events and disposal are owned by one immutable activation revision. Namespace command/panel/theme IDs within each package; reject duplicate contributions and validate semantic color tokens (plain or `--` prefix, hex values).
- Return synchronous sanitized descriptors without source paths, handlers, raw exceptions or stacks. Snapshot revision changes on activation, reload, enable/remove, contribution registration/disposal and recorded handler failures. UI assets are served only for the current active revision. A failed prepare/factory keeps the previous working activation and its original manifest capabilities; partial candidate contributions and disposal handlers are cleaned up.
- Invoke each command with a fresh frozen context and JSON input/result. Wrap every memory call with capability, explicit-write, abort, scope and activation checks before and after awaiting. Close the invocation after completion so retained contexts cannot operate later. Newer brain generations abort pending work and old generations are rejected; tabs within one generation remain independent. The gateway supplies observational `scope.changed` at startup and after committed target/permission generations. Other hosts can also learn a generation on its first authorized command/event; the app then delivers the notification before the original activity. Delivery is deduplicated by generation, so same-generation activity/duplicate notifications cannot cancel other tabs. Gateway memory implementations additionally enforce canonical IDs, target authorization, generation/drain barriers and save outcomes.
- Deliver observational events with writes disabled, irrespective of the caller's write authorization. Handler errors update extension status only; they cannot veto saves, target switches or core behavior. State APIs remain activation-fenced. Disabling/removing/replacing/disposal aborts activation-owned work and runs all owned disposers once; async disposers get a 1-second bounded wait each.
- Preserve policy error identity via `ExtensionPackageError.code`: `extension_invalid`, `extension_permission_denied`, `extension_stale`, `extension_failed`. Unexpected command errors retain `cause` for the gateway to recover only its own trusted error type; snapshots always use generic diagnostics.
- Bound factory/module loading to 3 seconds, command invocation to 15 seconds, a whole notification to 3 seconds. Node caches imported ESM permanently; permit at most 64 module import attempts per host lifetime, then require a host restart while retaining a prior working activation. Cache disk retention is separately bounded in the adapter. No background watcher, process per extension or polling loop is introduced.

The host records successful activation before publishing replacement contributions and falls back to the persisted successful manifest/revision after a failed restart candidate. Safe mode tolerates unreadable current/backup registries with an empty execution set and optional bounded `snapshot.recovery`, preserving damaged bytes; ordinary management errors remain explicit. One notification has a total three-second deadline across handlers/scope delivery. The internal host `cancelObservations()` hook also cancels notifications nested inside a command, without cancelling that command’s admitted memory transport. Observational contexts are cancelled by the gateway transition hook; only actual admitted memory operations drain the coordinator.


## Non-responsibilities

- Do not select canonical memory roots, authorize remote writes, retry saves, expose credentials or implement HTTP/native UI contracts. Gateway context operations retain those responsibilities.
- Do not promise preemption, process isolation or safe unloading of arbitrary trusted JavaScript. Timeouts fence later API calls/results but cannot interrupt synchronous code or reverse unmanaged side effects. Returned factory cleanup and registered disposers are cooperative; same-process crashes/unhandled detached errors can still terminate the host.
- Do not expose activation-time memory, generic shell/filesystem APIs, arbitrary browser fetch/native IPC or feature-specific optional product logic. The public SDK is a separate host-independent entrypoint.
