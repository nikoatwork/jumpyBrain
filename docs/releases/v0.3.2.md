# jumpyBrain 0.3.2 (beta)

- One Mac app now combines the desktop editor, menu bar, and bundled memory runtime. Closing its window keeps services available; Quit waits for open editors to save and stops only app-owned services.
- Added local-folder onboarding and reversible migration from the earlier two-app setup. CLI installation and updates remain independent.
- Open notes pick up external edits with a brief highlight. Independent edits can merge after typing settles; overlapping changes retain the draft for review.
- Added pinned/recent page navigation and bounded, inspectable diagnostic attachments for user-sent feedback.
- Refined memory lifecycle controls and reduced redundant sidebar, editor, and diagnostic work.
- Release versioning now keeps the CLI/runtime and Mac app package versions aligned.

## Install or update

For the Mac app, select this release in your checkout, quit jumpyBrain, and run `npm run desktop:setup`. Existing brains and connections are retained. The CLI has its own `jumpybrain update` workflow; its recorded source/ref determines the version it installs.

This remains a beta. Mac builds are local and ad-hoc signed; no signed/notarized Mac download is provided. The attached tarball is the CLI/runtime source distribution, not a portable Mac application. Physical-device, login, and broader browser QA remain separate gates.
