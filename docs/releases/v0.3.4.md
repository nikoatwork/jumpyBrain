# jumpyBrain 0.3.4 (beta)

- Added a software-update control at the bottom-right of the Mac sidebar, with an availability indicator, installation progress, retry, and a separate **Restart to update** action.
- The desktop app checks published releases at startup and every six hours. Installing verifies the release package and prepares a new Mac app while you keep working.
- Restart waits for open editor tabs to save, then uses the existing transactional installer after the app exits. Blocked saves leave the app running.
- Update controls are restricted to the installed Mac app. The separately installed CLI retains its own update workflow.

## Install or update

Existing versions do not contain the new sidebar updater. To get 0.3.4, update your trusted checkout to this release, quit jumpyBrain, then run `npm run desktop:setup`. See the [installation guide](https://github.com/nikoatwork/jumpyBrain/blob/v0.3.4/docs/install.md) for CLI and agent-assisted installation options.

After installing 0.3.4, future published updates can be prepared from the sidebar. Preparation requires the same Node/npm, Python and Xcode command-line tools as desktop setup and can take a few minutes. Choose **Restart to update** after preparation; quitting without that action requires preparing again on the next launch.

This remains a beta with locally built, ad-hoc-signed Mac apps. The attached `jumpybrain-0.3.4.tgz` is the CLI/runtime and desktop build-source distribution, not a portable notarized Mac installer. CLI/runtime and desktop package versions are aligned at 0.3.4. Markdown memories and connection settings are retained.
