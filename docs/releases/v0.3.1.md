# jumpyBrain 0.3.1 (beta)

- Added Ember light/dark themes and clearer beta labeling in the browser and Mac app.
- Added note lifecycle controls and immediate search feedback for recent writes.
- Extracted typed browser controllers and shared reference/search behavior while preserving save and conflict guards.
- Fixed remote operation deadlines and overview freshness; reduced repeated canonical discovery and indexing reads.
- Unified Mac installation/update/uninstall safety and removed obsolete bootstrap code. Quit now exits directly with graceful shutdown.
- Added a patch-by-default release command, with explicit minor releases and user approval required for major releases, including 1.0.

This remains a beta. The Mac app is built locally and ad-hoc signed; physical-device, login, and broader browser QA remain separate gates. The attached tarball is the CLI/runtime source distribution, not a portable signed Mac app.
