# jumpyBrain 0.3.3 (beta)

- Clarified local-first privacy: local Markdown storage and search need no jumpyBrain account or remote memory server. The FAQ explains cloud assistants, remote connections, user-sent feedback, and file-sync boundaries.
- Added a direct path from an existing CLI installation to the Mac app, reusing its source and opening the same memory folder. Corrected outdated private-repository and SSH setup instructions.
- Explained the app/CLI relationship, separate program updates, local services, optional semantic search, and uninstall behavior.
- Added agent installation guidance and updated the shipped memory skill to reuse existing installations, complete authorized setup without repeated confirmations, and report tool restrictions accurately.

## Install or update

Follow the [installation guide](https://github.com/nikoatwork/jumpyBrain/blob/v0.3.3/docs/install.md) or give your assistant the [agent installation guide](https://github.com/nikoatwork/jumpyBrain/blob/v0.3.3/docs/install-for-agents.md).

The CLI updater follows its recorded source/ref. To update the Mac app from the default managed CLI source, quit the app, update the CLI, then run `cd "$HOME/.jumpybrain/app" && npm run desktop:setup`. Select the same memory folder in the app to share notes with your agents.

Existing installed agent integrations are preserved by the updater; the new skill guidance is included in fresh installations and the source distribution. Existing users can read the linked agent installation guide directly.

The CLI/runtime and Mac app package versions are aligned at 0.3.3. This remains a beta with locally built, ad-hoc-signed Mac apps. The attached tarball is the CLI/runtime source distribution, not a notarized Mac application installer.
